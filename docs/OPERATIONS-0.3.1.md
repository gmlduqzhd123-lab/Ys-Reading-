# 책숲 0.3.1 운영 보완

- 교사 초대·복구 점검 시각은 한국 시간과 24시간 표기를 사용한다. 서버 ICU의 `PM`과 브라우저의 `오후` 차이로 발생하던 hydration 오류를 제거한다. 브라우저 회귀 검사에서 hydration 및 미처리 오류는 실패한다.
- 백업 상태 API의 404, 잘못된 응답, 미래·누락 시각은 정상으로 인정하지 않는다. 최신 서버 백업이 생긴 뒤 2시간 동안 복원 검사를 기다리고, 그 뒤에는 GitHub의 기존 백업 알림에 검증 지연 사유를 표시한다. PC 백업의 실패를 서버 검증 경고로 덮지 않는다.
- `operator-cloud-backup.mjs setup`은 기존 로컬 복구 키만 읽는다. 기존 서버 공개 키와 다르면 교체를 거부하며, 동시 변경도 비교 후 갱신으로 방어한다. 자동 키 교체는 하지 않는다. 원래 복구 키·기존 복구 키트는 보존한다.
- `node scripts/operator-cloud-mirror.mjs configure <전체 경로>`는 실제 USB·네트워크 경로만 허용한다. 이후 기존 PC 예약 작업이 검증된 암호화 파일을 복사하고 해시를 다시 확인한다. 키는 복사하지 않는다. 외부 경로가 등록되기 전에는 비활성이다. 이 PC의 바탕화면 폴더는 외부 보관이 아니다. 공급자 전체 장애 중에도 독립적으로 실행되는 원격 복원 서비스는 별도 구축이 필요하다.
- 일괄 내보내기는 생성 당시 내용을 7일간 고정한다. 현재 원본의 동의·회원·교사 권한·삭제 상태가 바뀌면 고정 사본도 받을 수 없다. 이전 방식으로 만든 묶음은 다시 만들어야 한다. 최신 글 선택은 해당 미션의 최신 버전을 기준으로 하며, 검토 완료 선택은 독서 확인/글 완료만 포함한다.
- Word·CSV 분할 파일은 ZIP 한 개로 다운로드한다. 묶음 원문은 16MB, 생성 파일 합계는 64MiB로 제한한다. 로컬 ZIP은 재접속 시 고정 내용 전체를 재생성하며, Google 형식은 기존 부분부터 이어간다. 다운로드된 파일은 앱 밖 사본이므로 사용자가 별도로 관리한다.
- 학급 소유 교사는 관리 화면에서 학생 메뉴 간편 보기와 새 독서 기록 작성 도움을 설정한다. 추가 메뉴는 접기만 하며 접근 권한을 바꾸지 않는다. 여러 학급을 함께 보는 화면은 전체 메뉴를 표시한다.
- 교사 계정 관리·협업 초대·학기 종료·내보내기·화면 설정에 Axe, 키보드 접근 및 브라우저 오류 검사를 추가했다. CI의 합성 계정 검사는 실제 학교 기기·학교망 확인을 대신하지 않는다.

대체 운영자 본인 수락, 국내 도서 API 키 발급, 실제 외부 보관처 지정은 소유자의 준비가 필요하다.
