## 체험 순서

1. 체험 교실에서 선생님 역할로 미션을 배정한다. 기본 미션은 고쳐 쓰기 활동이다.
2. 학생 역할로 바꿔 예시 초고를 불러오거나 직접 쓰고 체험 제출한다.
3. 선생님 역할로 구체적인 피드백과 수정 요청을 남긴다.
4. 학생 역할로 글을 고치고 수정 이유를 적어 새 버전을 제출한다.
5. 선생님 역할로 완료 처리한다. 완료된 제출본이 작품 보관함에 들어간다.
6. 비교실·모험 지도·생각나무에서 변화를 확인한다.
7. 인터뷰·선택의 마을·생각 카드는 독립적으로 이용하고 작품을 보관할 수 있다.
8. 대회 준비 공방에서 완료본을 점검해 체험 출품한다. 교사 역할에서 심사를 확정하고 발표하면 학생 역할에서 결과를 확인한다.
9. 작품집에서 원하는 글을 골라 순서를 정하고 파일을 내려받는다.

## 저장과 내보내기

- `bookforest.studio.v1` 형식으로 브라우저 `localStorage`에 학습 글·활동·보관 작품·미션·꾸미기를 기록한다. 저장은 성공한 경우에만 기록됨으로 표시한다.
- 손상된 형식이나 다른 스키마 버전은 자동으로 덮어쓰지 않는다. 다른 탭에서 기록이 바뀌면 현재 탭의 입력을 중단해 덮어쓰기를 막는다.
- 저장 공간 부족 시 현재 글은 메모리에 남기며 백업과 재저장을 안내한다. 미저장 상태로 창을 닫을 때 경고한다. 브라우저 종료·강제 종료·저장소 삭제 이후 복구를 보장하지 않는다.
- 기록 백업은 형식 버전·백업 날짜를 담은 JSON 파일이다. 이전에 내려받은 일반 JSON 백업도 불러올 수 있다. 작품집과 활동지는 HTML 파일로 내보내며, 파일을 열어 브라우저 인쇄 또는 PDF로 저장을 이용한다.
- 초기화는 이 브라우저의 놀이터 기록에만 적용한다. 실제 교실 데이터에 영향을 주지 않는다.
- 피드백·심사 의견·점수는 확정 버튼을 누를 때 보관된다. 작성 중인 해당 입력은 도구를 벗어나면 유지되지 않을 수 있다.

## 백업 복원 방법

1. 현재 기록이 필요하면 먼저 ‘기록 백업’으로 내려받는다.
2. 상단 ‘백업 불러오기’에서 책숲 JSON 파일을 고른다. 최대 크기는 8MB다. 파일 선택만으로 현재 기록이 바뀌지 않는다.
3. 백업 날짜, 제출·완료 글 수, 작품·미션·작품집 선택 수, 초안 유무를 확인한다.
4. 현재 기록이 백업으로 교체된다는 확인란을 선택한 뒤 복원 버튼을 누른다. 현재 기록과 합치지는 않는다.
5. 저장 성공 뒤 복원 완료 안내가 나타나고 전체 도구로 돌아간다.

파일 형식·버전·용량·작품 연결이 맞지 않거나, 파일을 고른 뒤 현재 기록·다른 탭의 기록이 바뀌면 복원하지 않는다. 저장 실패 때는 기존 저장 기록과 화면을 유지한다. 읽지 못한 기존 저장 기록은 ‘기록 백업’으로 원본 그대로 내려받을 수 있으며, 이 원본이 바로 복원 가능한 파일이라는 의미는 아니다. 파일은 외부로 전송하지 않는다.

## 계정 연결 이후 남은 범위

이 놀이터의 역할 선택과 체험 점수는 실제 인증·권한·학급·대회 결과로 사용하지 않는다. 실제 교실 데이터의 접근 정책과 서버 검증은 기존 `/app`에 유지했다.

기기 간 동기화, 실제 교실 기록의 지도·정원·작품집 반영, 새 교사 미션의 서버 저장·학급 배정은 계정 연결 후 별도 구현·검증이 필요하다. 실제 작품의 외부 공개·전송은 이번 기능에 포함하지 않는다.

검사 결과와 브라우저 검증 제한은 `VERIFICATION.md`에서 확인한다.
