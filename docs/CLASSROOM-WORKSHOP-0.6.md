# 책숲 0.6.0 · 매일 독서와 수업 공방

2026-11-13 승인된 벤치마킹 제안 10가지를 기존 책숲에 연결했다. 다른 서비스의 코드·그림·활동지를 가져오지 않으며 책숲의 질문 양식·그림 기호·교사 작성 콘텐츠를 사용한다.

|---|---|---|
| 1 | 오늘 읽던 책 선택 → 구절·한 줄 생각 → 저장 | 기존 독서 기록장에 저장. 학급별 생각/구절/모두 기준. 같은 학생·학급·한국 날짜·책의 간편 기록은 중복 생성하지 않는다. 완독·보상은 별도 교사 확인 |
| 2 | 학급 설정·배부 버전을 반영한 학생 화면 시연 | 교사의 읽기 전용 시연. 가상 학생을 표시하며 실제 학생 인증·제출·보상을 실행하지 않는다. `/studio`의 별도 브라우저 체험 경계도 유지 |
| 3 | 활동지 6종 시작 양식, 편집·온라인 배부·동일 버전 A4 인쇄, 교사 갤러리 | 양식 revision, 배부 snapshot, 제출 version을 분리. 교사만 공개·복제. 학생 작품은 양식 공유에 포함하지 않음. 종이 활동은 학생 온라인 제출을 대신 작성하지 않고 교사 확인·관찰로 따로 기록 |

## 진입 경로

- 학생: 오늘 할 일/나의 책장의 간편 독서 기록, ‘우리 반 활동·책숲 도감’ → `/classroom`.
- 교사: ‘우리 반 수업 공방 · 학생 화면 시연’ → `/classroom`. 학급 선택은 기존 RLS로 허용된 목록만 제공한다.
- 근거: 성장 보고서 준비 화면의 원기록 확인, `/classroom/activity/<배부 id>`의 권한 검사된 원기록.
- 보호자: 교사가 복사한 `/family#<무작위 값>` 링크. 비밀 값은 URL fragment에서 메모리로 읽은 뒤 주소에서 지우고 POST 본문으로만 확인한다. DB는 해시만 저장한다. 새로고침으로 값이 사라지면 받은 원래 링크로 다시 연다. 공유는 자동 이메일로 발송하지 않는다.

## 운영·데이터

모든 새 학습 테이블은 private 스키마의 RLS+직접 접근 차단으로 보관한다. 인증 RPC는 현재 세션·담당 학급·참여 동의·마감·최신 버전을 검사한다. 공동교사는 읽기/검토 권한을 구분하며 학급 설정·배부·도서 등록·보호자 공유는 담임 권한이다. 보관된 학기는 읽기와 기존 공유 해제만 가능하다.

새 활동·종이 관찰·요청 사본을 기존 승인된 자료 삭제 절차에 포함한다. 복구 검사는 보호자 링크를 모두 해제하여 오래된 링크가 복원으로 되살아나지 않게 한다. 실제 다른 서버 전환·외부 장치 보관·학교 실물 기기 검증은 이 개발의 자동 통과 결과와 구분한다.

AI SDK는 7.0.172로 고정했다. 선택 기능은 `BOOKFOREST_AI_QUIZ_ENABLED=true`, 현재 모델 목록에 있는 `BOOKFOREST_AI_MODEL`, `AI_GATEWAY_API_KEY` 또는 Vercel OIDC가 모두 준비되어야 한다. 기본값은 비활성이며 새 결제·키 발급·예산 변경을 자동으로 수행하지 않는다. 모델은 고정된 옛 이름을 추정하지 않고 Gateway 목록으로 재검사한다. 교사가 직접 쓴 설명만 전달하며 학생 기록을 자동 조회해 보내지 않는다. 모델 응답은 문항 형식과 입력 설명의 근거 문장 일치 검사를 거치고 교사가 저장·배부 전에 검토한다. API 미설정 상태에서는 실제 AI 생성 성공을 표시하지 않는다.

## 검증

단위·DB 검사와 격리된 실제 Supabase Auth/Postgres 브라우저 CI로 검증한다. 새 교실 전용 합성 계정은 GitHub의 localhost 프로젝트에만 생성한다. 운영 학생·학급을 검사 자료로 만들지 않는다. 실제 통과 수·커밋·배포·백업은 릴리스 검증 파일과 해당 GitHub Actions를 기준으로 확인한다.
