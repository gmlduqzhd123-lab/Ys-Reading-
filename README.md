# 책숲 · Bookforest

초등학생이 책을 읽고 질문을 만들고 글을 고쳐 쓰는 독서인문교육 웹앱입니다. 교사의 학급 준비부터 학생의 읽기·글쓰기, 피드백, 공동 전시와 경제 교실까지 연결합니다.

소스 저장소: [gmlduqzhd123-lab/Ys-Reading-](https://github.com/gmlduqzhd123-lab/Ys-Reading-). GitHub에서 소스와 자동 검사 결과를 관리하고, Supabase에 계정과 기록을 보관하며, Vercel에서 [공개 책숲](https://reading-blush-zeta.vercel.app)을 제공합니다.

## 실행

Node.js 24와 npm을 사용합니다.

```sh
npm ci
npm run typecheck
npm test
npm run build
npm run start
```

공개 소개·미션 목록·책숲 놀이터는 데이터베이스 없이도 열립니다. 놀이터의 학습 기록은 이 브라우저에만 보관됩니다. **실제 교실의 로그인·글 저장·학급 운영에는 Supabase 설정과 마이그레이션이 필요합니다.** 환경이 없으면 실제 교실은 연결 준비 안내를 보여줍니다. 놀이터의 역할 선택은 실제 계정이나 권한을 만들지 않습니다.

프로젝트 연결 및 계정 준비는 [설정 안내](docs/SETUP.md)를 따릅니다. 선택이 확인되지 않은 기존 원격 프로젝트에는 마이그레이션을 실행하지 않습니다.

## 아직 필요한 작업

이 소스가 PRD 전체 또는 실제 학생 운영 준비를 완료했다는 의미는 아닙니다.

- Google OAuth의 학교 계정 정책·외부 사용자 공개 요건 확인과 실제 학급·학생의 수업 운영 검증. 공개 앱의 가상 기록 Docs·Sheets 생성과 가상 계정의 학급 흐름은 확인했습니다.
- 실제 운영자·교사 계정 준비와 학교의 동의 근거 확인. 관련 운영 화면과 Supabase Auth 연동은 구현했습니다.
- 기관 모델 확장과 외부 심사위원 배정, 대회 접수본 교체·철회.
- 글쓰기 활동 결과 확정/공개 단계 분리 등 확장. 학급·학년 전시의 별도 동의·교사 승인·참여 취소와 기존 광장 신고 처리는 구현했습니다.
- 학교의 보관 기간 확정, 실제 기기 및 동시 사용자 성능·복구 검증. 수동 승인 삭제와 학급 인계 기능은 구현했습니다.

초기 계정 준비는 운영자용 도구로 수행합니다. 실제 학생 계정은 동의 대기 상태로 생성됩니다. 가상 시험 계정 활성화에는 명시적인 개발 설정이 필요하며, 실제 법정대리인 확인을 대신하지 않습니다.

## 비밀정보

`.env.local`, `.vercel`, 빌드 결과, 계정 암호는 Git에 포함하지 않습니다. 일반 앱의 데이터 접근은 사용자 JWT와 RLS를 이용하며 운영자 비밀키는 계정·콘텐츠 준비 스크립트에서만 사용합니다. 작품 본문이나 피드백을 분석 로그에 기록하지 않습니다.
