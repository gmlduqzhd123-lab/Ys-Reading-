# 책숲 0.8.0 · 운영 신뢰성과 작성 보호

1. **알림 전달:** 백업 감시 작업이 별도 경로로 GitHub 점검의 알림 단계까지 확인합니다. 완료 신호 60분 지연, 알림 단계 실패, 조회 실패를 구분하며 PC 감시 보고도 45분 신선도를 검사합니다. PC가 꺼져 있거나 보고가 없으면 서버가 고정된 저장소의 공개 GitHub 실행 정보를 최대 5분 캐시로 확인하므로 PC 중지만으로 알림 전달 실패를 만들지 않습니다. 전용 HMAC 보고는 백업 성공·계정 권한을 바꾸지 않습니다. 설치된 DB를 확인한 뒤 `node scripts/operator-enable-delivery.mjs`로 기존 PC 감시에 연결합니다. GitHub 전송은 제한된 재시도와 전달 식별자로 잃어버린 POST 응답을 대조해 중복 이슈·댓글을 줄입니다. GitHub 전체 장애나 예약 실행 지연을 없앴다고 보장하지 않습니다. 별도 GitHub App/토큰을 발급하지 않고 임의 권한으로 예약을 강제 실행하지 않습니다.
2. **전체 기록 조회:** 기존 `/app`은 화면·학급별 30건 페이지로 조회하고 연결된 원기록만 가져옵니다. 편집기는 해당 배정만 조회하며 제출 이력을 넘겨도 최신 제출본을 함께 유지합니다. 교사 검토는 최신 제출 버전을 고른 후 상태를 필터링합니다. 학년 연결 코드는 반환하지 않습니다. 허브의 명단·설정 메타데이터도 안정적인 순서로 끝까지 읽고, 중간 실패를 전체 명단 성공으로 표시하지 않습니다.
3. **복구 훈련:** 기존 격리 PostgreSQL·Auth·계정 작업자·브라우저·암호화 복구 흐름을 매주 일요일 04:41 한국 시각에 GitHub로 예약합니다. 실행 지연은 가능하며 성공 여부는 해당 실행으로 확인합니다. 실패 알림은 별도 이슈 하나를 유지하고 전체 훈련 성공 이후에 닫습니다. 알림 권한은 검토된 main의 별도 작업에만 줍니다. 운영자 화면은 실제 백업·외부 사본·별도 제공자 상태와 본인이 기록한 복구 이력을 구분하고 키 없는 준비 점검표를 내려받습니다. 별도 실물 PC·외부 보관처·운영 서버 전환은 자동 완료로 표시하지 않습니다.
4. **개인 기기 초안:** 쓰기·독서·교사·수업 초안에서 본인만 쓰는 개인 기기를 직접 확인한 경우에만 선택합니다. Web Crypto의 PBKDF2와 AES-GCM을 쓰며 암호·키는 서버에 보내거나 디스크에 저장하지 않습니다. 암호문과 검증용 공개 매개변수만 브라우저에 저장합니다. 키는 브라우저 메모리에서 잠그며 로그아웃 때 비웁니다. 15분 동안 보관 기능을 사용하지 않으면 다시 열어야 합니다. 7일 이내 초안 최대 10개를 불러올 수 있고 만료 자료는 다음 사용 시 정리합니다. 공용 기기는 기본 비활성이며 파일 보관·서버 초안은 기존대로 유지합니다. 다른 탭이 바꾼 사본은 비교 후 선택하며 현재 입력을 조용히 덮어쓰지 않습니다. 복원은 최종 제출·공개·보상을 실행하지 않습니다. 현재 권한·동의가 없는 서버 작업은 기존 검사로 거부합니다. 이미 남긴 오프라인 암호문을 서버의 삭제 승인만으로 원격 회수한다고 표시하지 않습니다.
5. **주간 요약:** 교사 현황판에서 한국 날짜 기준 월~일의 독서 날짜·글 제출판·고쳐쓴 판·피드백과 전주 건수를 확인합니다. 현재 참여·동의·삭제 보류·담당 교사의 읽기 권한을 기존 기록 검색과 같은 함수로 검사합니다. 글 원문은 요약 RPC로 보내지 않습니다. 현재 7일 이상 교사 확인을 기다리는 최신 글은 최대 20건을 먼저 보여주고 학생 원기록 조회로 연결합니다. 성적·학교 출결·자동 평가로 사용하지 않습니다.
6. **운영 정리:** `config/feature-status.json`에서 기능 문서를 생성하고 CI에서 버전·검사 경로·생성 문서 일치를 확인합니다. `node scripts/operations-report.mjs`는 공개 상태를 필요한 필드만 모아 JSON으로 저장합니다. `--operator`는 기존 프로젝트 한정 연결로 운영자·초대·기록된 훈련 건수만 추가하며 이메일·키·학생 자료는 넣지 않습니다. 미확인은 정상으로 바꾸지 않습니다. `--require-current`는 배포 커밋·서비스·백업 검증을 확인하는 릴리스용 옵션입니다. GitHub 가용성 작업도 비공개 내용을 제외한 보고서를 14일 보관합니다.
