# 책숲 현재 개발 상태 · 0.8.0

현재 구현 항목과 사용자 준비 조건은 자동 생성되는 [기능·준비 현황](FEATURE-STATUS.md)을 기준으로 확인합니다. 코드 변경 후 `npm run docs:sync`, CI에서 `npm run docs:check`로 누락을 검사합니다.

이번 6가지 개선은 [운영 신뢰성과 작성 보호](OPERATIONS-0.8.md)에 설명합니다. 실제 연결 상태는 `/status`, 배포 커밋의 GitHub Actions와 `node scripts/operations-report.mjs`의 시각별 JSON을 기준으로 확인합니다. 구현됨은 외부 승인이나 실제 운영 전환 완료를 뜻하지 않습니다.

학급·학생 발급·동의·독서·글쓰기·교사 확인·보상·경제·진급·공동교사·보호자 공유·Google/파일 내보내기를 유지합니다. 기존 운영 이력은 [0.7.0 당시 상태](releases/0.7.0-status.md), [수업 기록 복구와 이력 관리](CLASSROOM-OPERATIONS-0.7.md)에 보존합니다.

외부 저장처 지정, 대체 운영자의 본인 수락·MFA, 국내 도서 API 키 발급, 다른 실물 PC·별도 운영 클라우드 전환은 준비 도구와 실제 확인을 구분합니다. 같은 PC 폴더와 같은 제공자의 암호화 보관은 독립 외부 백업으로 표시하지 않습니다.
