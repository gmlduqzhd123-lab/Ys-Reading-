# 책숲 0.4.0 · 교사 작성 보호와 내보내기 운영

1. 내보내기는 계정별 유효 묶음 10개, 한국 날짜 기준 새 묶음 20개/일, 보관 원문 64MiB를 제한한다. 묶음은 7일간 유효하며 기존 묶음 삭제는 원래 학생 기록을 삭제하지 않는다. 삭제해도 당일 생성 횟수는 돌려주지 않는다. 동일 요청 UUID와 조건 재시도는 같은 묶음을 돌려주며 조건이 바뀐 재사용은 거부한다. 기존 RPC에도 같은 한도를 적용한다. 다운로드·Google 요청은 계정별 분당 60회 한도를 적용한다.
2. PC 예약 작업은 기본 백업, 복구 묶음 사본, 외부 미러의 실행 결과를 각각 확인한다. 실패한 실행에서 오래된 성공 영수증을 다시 사용하지 않는다. 설정된 사본의 복사·검증·보고 실패는 예약 작업을 실패시키며, HMAC 서명과 순번으로 보호한 최소 상태만 서버에 보고한다. 상태 화면과 기존 GitHub 백업 경고가 사본 실패·보고 지연을 표시한다. 같은 PC의 바탕화면 사본은 외부 보관으로 표시하지 않는다. 미설정 외부 미러는 장애로 처리하지 않는다.
3. 교사 검토 피드백·성장 보고서·학생 화면 설정은 본인만 읽을 수 있는 서버 초안으로 7일간 보관한다. 1초 대기 후 저장하고 새로고침 시 직접 불러온다. 학급 권한·현재 학생 동의를 매번 검사하며 동시 편집은 revision 충돌로 중단한다. 초안 복원은 원문 읽음·학생 공개·최종 확인·보상을 실행하지 않는다. 최종 저장은 별도 버튼과 기존 권한 검사를 사용한다. 로그아웃·계정 전환 시 메모리를 비운다. 저장 전 이동에는 확인을 제공하고, 연결 실패 시 현재 입력을 파일로 보관할 수 있다.
4. Word·CSV 묶음은 서버에서 부분 파일을 만들어 DB에 보관한다. 탭을 닫아도 `pg_net` 작업과 매분 복구 cron이 이어간다. 한 부분은 최대 25건·3MiB이며 생성 파일 보관은 계정별 64MiB·전체 128MiB, 작업 호출은 계정별 1,000부분/일·전체 5,000부분/일로 제한한다. 실패한 부분은 최대 3회 시도하고, 명시적 재시작은 완료 부분을 재사용한다. 한 번만 사용할 수 있는 비공개 작업 식별자와 lease로 재실행·취소 후 이전 작업의 쓰기를 차단한다. 사용자 토큰·서비스 키를 작업 요청에 넣지 않는다. 생성·확정·다운로드 때 실제 세션·현재 RLS를 다시 검사한다. 다운로드 전 전체 접근을 확인하고 각 부분의 SHA-256을 검사하며 ZIP을 순차 전송한다. 브라우저가 모든 파일을 모아 압축하지 않는다.
5. 교사 현황판의 학생별 최근 활동은 현재 담당 학급 범위의 기록을 한 번 집계해 연결한다. 독서 최신 활동·완독 검토 대기 인덱스와 내보내기 선택의 CTE 계획을 보완한다. 기존 동의·권한·최신 제출 규칙은 유지한다. 3개 학급 90명 동시 검사와 30,000개 과거 기록 검사는 실제 PostgreSQL CI에서 수행한다.

## 복원 시 주의

내보내기 묶음·원문 고정 사본·생성 파일·작업 capability·요청 한도는 정본에서 재생성할 수 있는 임시 자료이므로 전체 백업에서 **스키마만 보관하고 행은 제외**한다. 학생 정본·교사 초안·계정·권한·경제 원장은 계속 백업한다. 복구 후 내보내기 묶음은 새로 만들고, `private.zip_worker_config`를 검토한 서비스 주소로 다시 설정한다. 이전 작업을 자동 재가동하지 않는다. 함수 소유자 `bookforest_export_reader`는 NOLOGIN·NOBYPASSRLS여야 하며 실제 복구 대상에서 역할·권한을 별도로 검증한다. PGlite의 구조·행 복원 통과만으로 운영 전환 완료를 뜻하지 않는다.

실제 학교 기기·학교망, 대체 운영자 본인의 수락, 국내 도서 검색 키 발급, 외부 보관처 지정은 별도 준비 사항이다.
