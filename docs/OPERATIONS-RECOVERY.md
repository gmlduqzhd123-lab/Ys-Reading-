# 운영 규모 확대와 복구 점검

> 2026-11-02 최신 운영 설명은 [OPERATIONS-EIGHT.md](OPERATIONS-EIGHT.md)를 우선합니다. 아래 과거의 미완료·미설정 표기는 당시 이력입니다.

2026-11-02 기준 구현 범위입니다.

- 종료 학급은 학생 오늘 할 일·교사 확인 대기에서 제외합니다. 지난 기록의 읽기·검색·파일 내보내기는 기존 권한으로 유지합니다.
- 오늘 할 일은 본문 없이 8개, 교사 확인함은 최신 제출과 미확인 완독 기록을 20개씩 서버에서 읽습니다. 종류별 전체 수와 각 페이지를 별도로 반환합니다. 다른 학급·철회된 참여 권한은 데이터베이스에서 검사합니다.
- UTF-8 CSV `아이디,별칭`을 최대 300명까지 미리 검사하고 30명씩 발급합니다. 비밀번호는 브라우저 메모리와 교사가 저장한 안내표에만 남습니다. 네트워크 실패 시 같은 요청 ID로 남은 발급을 이어갑니다.
- 진급 명단은 50명씩 확인하고 같은 다음 학급에 나머지 명단을 추가할 수 있습니다. 새 학급 참여 근거를 확인한 요청만 운영자가 일괄 승인하며, 담당 교사가 승인된 학생을 명시적으로 선택해 시작합니다. 학급 화폐는 이전하지 않습니다.
- 담당 교사가 인계를 요청하고 운영자가 기존 교사를 확인해 다음 담당 교사로 인계합니다. 권한 변경과 중복 요청 처리는 원자적 명령으로 실행합니다.
- Google 연결 표시는 브라우저 쿠키 유무와 실제 API 확인을 구별합니다. 실제 확인은 만료 토큰 갱신 후 제한된 Drive 요청을 수행합니다. 학교 정책 거절·용량 부족·일시 제한을 구별하고 파일 내보내기 대안을 제공합니다.

## 운영자 전용 로컬 백업

프로젝트 루트에서 `node scripts/operator-backup.mjs`를 실행합니다. 현재 Codex 사용자의 책숲 Supabase MCP 인증이 필요하며 다른 프로젝트에서는 중단합니다.

기본 위치는 `%LOCALAPPDATA%\Bookforest\OperatorBackups\rbtqtkjnqtcnljvabisa`입니다. 디렉터리 상속 권한을 끄고 현재 사용자와 SYSTEM만 허용합니다. AES-256-GCM 키는 Windows DPAPI CurrentUser로 감싸 별도 보관합니다. 키·평문 스냅샷·비밀번호 해시는 저장소나 로그로 출력하지 않습니다.

계정과 비밀번호 해시·권한·학습 기록·경제 원장·앱 마이그레이션·현재 함수와 접근 정책을 한 스냅샷으로 암호화합니다. Auth 세션·일회용 토큰은 복원하지 않습니다. Google Drive 파일·Supabase 관리 설정·환경 변수·외부 서비스 구성은 별도입니다. 현재 앱은 Storage 객체를 사용하지 않습니다. 임의의 Supabase 클러스터를 그대로 복제하는 도구가 아닙니다.

매 백업은 저장한 암호문을 다시 복호화한 뒤 별도 PGlite PostgreSQL에서 스키마 재생, 데이터 삽입, 전체 행 내용 비교, 외래키 검증, RLS·함수 권한 재적용, 익명 접근 차단을 검사합니다. 통과한 결과의 파일명·해시·수량만 서버 상태 화면에 기록합니다. 복구 검사는 운영 데이터베이스에 쓰지 않습니다.

기존 백업 재검사: `node scripts/operator-backup.mjs --verify=C:\…\날짜.bfbak`. 이 도구는 현재 프로젝트 보관 폴더 안의 파일만 받습니다. 실제 장애 시 새 프로젝트에 복구하고 인증·서비스 설정까지 검증한 뒤 전환해야 합니다. 현재 운영자 PC에는 예약 백업·암호화 복구 키 내보내기를 구성했습니다. 최신 자동 점검·인증 복구 절차는 [BACKUP-MCP-RECOVERY.md](BACKUP-MCP-RECOVERY.md)를 따릅니다. 다른 실물 PC에서의 복구 확인은 별도입니다.

## 확인한 증거와 한계

- 전체 자동 검사 349개, TypeScript 검사, 프로덕션 빌드 통과.
- 실제 Supabase 가상 계정으로 기본 학습·보상·경제 흐름 25개 및 새 대량 처리·종료·진급·인계 흐름 12개 검사 통과. UI에서 중복 CSV 발급 차단, 정상 두 명 발급, 안내표 다운로드를 확인했습니다.
- 실제 데이터에 대한 암호화 백업과 격리 복원: 87개 테이블·131개 외래키·71개 정책. 가상 학습·경제 원장이 들어 있는 206개 행 백업도 내용 비교를 통과했습니다.
- 실제 서버에서 동시에 20개 확인함 요청을 보내 전체 25개 기록이 20/5개 페이지로 누락·중복 없이 반환되는 것을 확인했습니다. 대규모 학교 전체 부하나 실제 학교 기기의 검증은 아닙니다.
- Supabase 보안 진단의 인증 사용자용 SECURITY DEFINER 경고는 서버 역할·학급·동의·세션 검사를 둔 의도된 명령에 해당합니다. private 요청/백업 테이블은 정책 없는 RLS로 직접 접근을 차단합니다. 기존 유출 비밀번호 검사 미설정 경고는 별도 운영 설정입니다.
- Google 일반 공개 게시 및 실제 학교 Google 계정 연결은 Google 콘솔의 공개 상태·해당 학교 관리자 정책을 별도로 확인해야 합니다. 앱 코드의 성공 검사만으로 일반 교사 계정 승인을 주장하지 않습니다.
