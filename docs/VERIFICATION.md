# 책숲 개발 검증 기록

## 2026-10-30 · 실제 계정용 4단계 기능

`npm run check` 통과: 타입 검사, **11개 파일의 165개 자동 검사**, 프로덕션 빌드. 실제 연결 설정을 사용한 빌드에서 정적 페이지 33개를 생성했다. 원격 적용 이력에 맞춰 마이그레이션 파일 이름을 정렬한 뒤 DB 검사 28개를 추가로 재확인했다.

- **로컬 DB 자동 검사:** 학급 간 접근 차단, 동의 대기 제한, 독서 기록 revision 충돌·확인 후 불변성, 하루·학급별 출석 중복 방지, 구매 재시도·재고·잔액·환불, 학생 공유 선택·교사 승인·철회, 승인 전후 학년 접근, 학년 글쓰기 접수, 월간 동률·한국 시각 월말 경계, 활동 중지 이후 획득 경험치 보존을 PGlite에서 검사했다.
- **내보내기·인증 보호 자동 검사:** 허용되지 않은 기록이 섞인 요청 전체 거부, 선택 순서, HTML 이스케이프·CSV 수식 무력화, 실제 DOCX 구조, 동의 제한, OAuth 쿠키 변조·다른 계정·다른 용도의 재사용 거부, 요청 Origin 검사, 새 경로의 인증 갱신과 private/no-store 헤더를 확인했다.
- **실제 Supabase, 가상 계정:** 선택한 프로젝트의 가상 교사·학생으로 Auth 로그인을 확인했다. 초대·연결 신청·교사 승인, 독서 기록 저장·확인·중복 보상 방지, 미션 배정·초안·제출·완료, 공유 신청·게시 승인, 글쓰기 접수·검토·발표·학생 결과 조회, 학년 모임 승인과 다른 학급에서 연 활동 접수, 구매 재시도·장식 지급을 확인했다. 실제 교사·학생을 검증한 것은 아니다.
- **실제 앱 서버:** 가상 계정 쿠키로 학생·교사 각각 6개 화면에서 HTTP 200을 확인했다. 실제 도서 검색은 Open Library에서 한글 검색 결과 2개를 반환했다. 독서 기록·제출 글의 DOCX·CSV·인쇄용 HTML 응답과 DOCX 내부 한글 본문을 확인했다. 외부 Origin, 접근 불가 ID, 비로그인 도서 검색은 차단됐다.
- **브라우저:** 실제 Supabase 세션을 사용하는 로컬 앱에서 책 검색·메타데이터 자동 입력·독서 기록 저장과 목록 반영을 클릭 확인했다. Word 다운로드 완료도 확인했다. 최종 빌드 새로고침 이후 수집한 새 콘솔 오류·경고는 없었다. 성장 화면의 390×844 브라우저 뷰포트에서 페이지 가로 넘침이 없음을 확인했다. 이는 실물 모바일 기기 검증이 아니다.
- **DB 최종 상태:** 검증에 만든 가상 인증 계정 2개와 학급·독서·거래 자료를 식별자·테스트 표식·관계 검사로 제한해 제거했다. 원본 미션 18개를 유지했고 공개 테이블 27개 모두 RLS가 활성화됐다. 로컬 마이그레이션 버전은 실제 Supabase 이력과 일치한다.

Google Docs·Sheets의 실제 OAuth 앱 설정·교사 승인·Google 파일 생성은 **미실행**이다. 연결·생성 코드는 있고 설정 전에는 준비 안내를 표시한다. 실제 PDF 저장 대화상자·물리적 인쇄·학교 실물 기기·실제 수업·실제 운영 계정 발급·웹 호스팅 공개 배포도 이번 검증에 포함하지 않는다. Supabase 보안 점검의 의도된 SECURITY DEFINER RPC 주의 항목과 운영 전 조건은 `FOUR-STAGES.md`를 참고한다.

## 2026-10-30 · 백업 미리보기와 복원

확인할 흐름: `/studio`에서 백업 JSON 선택 → 형식·크기·작품 연결 확인 → 기록 요약 미리보기 → 사용자의 교체 확인 → 브라우저 저장 성공 → 복원 상태 표시. 실제 계정·서버 데이터는 사용하지 않는다.

`npm run check` 통과: 타입 검사, **6개 파일의 125개 테스트**, 프로덕션 빌드. 정적 페이지 27개 생성.

- 신규 백업의 형식 버전·날짜·데이터 왕복, 이전 일반 JSON 호환, UTF-8 BOM, 손상 파일·버전·날짜·출품 연결·실제 바이트 크기 검사.
- 파일 선택 시 저장하지 않음, 새 기기 복원, 지정 키에 한 번 기록, 선택 후 다른 탭 변경 거부, 저장 공간 부족·읽기 실패 시 기존 저장 내용 유지 등 새 검사 20개 통과.
- 복원된 제출·완료·출품·심사·발표·꾸미기·작품집을 검사에서 다시 읽고, 성장 기록과 작품집 생성을 확인.
- 로컬 프로덕션 서버 `/studio` HTTP 200, ‘백업 불러오기’와 최대 크기 표시, 기기 내 체험 안내 확인.
- 읽지 못한 기존 저장 기록은 빈 초기값 대신 원본 파일로 백업하도록 코드 보완.

브라우저 도구의 상태를 다시 확인했으나 Work 설정에서 비활성화되어 있었다. 실제 파일 선택·교체 확인·다운로드·새로고침 및 모바일 시각 검증은 수행하지 못했다. 파일 파싱과 저장 실패 검사는 자동 검사에서, UI 진입 표시는 서버 출력에서 확인한 범위다.

계정 연결·원격 데이터 변경·온라인 배포는 수행하지 않았다. 사용 절차는 `FEATURES.md`의 백업 복원 방법에 추가했다.

**현재 브라우저 자동 확인은 Work 설정에서 비활성화되어 있다.** 이번 변경의 실제 화면 클릭, 브라우저 저장·새로고침·다운로드, 모바일 시각 검증과 콘솔 확인은 실행하지 못했다. 위 렌더링 검사는 React의 정적 출력 검사이며 브라우저 상호작용 검증을 대신하지 않는다. 이전 날짜의 화면 캡처는 새 놀이터의 검증 자료가 아니다.

새 기능은 사용자 요청에 따라 브라우저 내 학습 공간으로 구현했다. 원격 계정 연결·배포는 수행하지 않았다. 실제 교실 기록의 새 도구 연동·기기 간 동기화·교사 미션 서버 배정은 후속 범위다. 자세한 이용 방법은 `FEATURES.md`를 참고한다.

## 브라우저에서 확인한 내용

로컬 주소 `http://127.0.0.1:3077`의 프로덕션 서버를 사용했다.

- 홈과 독서미션 목록·상세 화면 표시.
- 전체 18개 미션 → 공감 주제·5–6학년 선택 시 3개 표시.
- 일치하지 않는 검색어의 빈 결과 안내, 필터 초기화 후 18개 복원.
- 미션 상세의 활동 단계 및 교실 입장 이동.
- Supabase 미설정 상태에서 연결 준비 안내, 로그인 입력·제출 비활성화.
- 390×844 모바일 화면의 홈·로그인·메뉴 열기와 링크 이동 후 닫힘.
- 닫힌 모바일 메뉴가 접근성 트리에서 제외되고 열림 상태가 전달됨.

## 구현되어 있지만 실제 연결 검증이 남은 내용

- 교사·학생 실제 로그인, 세션 갱신, 로그아웃, 교차 계정·학급 접근 거부.
- 교사의 미션 배정 → 학생 초안 → 제출 → 교사 피드백 → 재제출 → 완료·배지 흐름.
- 학급 대회 생성 → 완료 작품 출품 → 심사 → 결과 안내 흐름.
- 편집기의 연속 입력·저장 충돌·연결 끊김·재시도·내부 링크 이동 전 저장.

편집기는 새로고침·창 닫기 시 미저장 경고와 내부 링크 이동 전 저장 확인을 구현한다. 브라우저 뒤로·앞으로 이동은 저장을 시도하지만, 이동과 네트워크 실패가 겹칠 때 유실 방지를 보장하지 않는다. 오프라인 복구 저장은 후속 과제다.

## 외부 서비스 상태

Git 저장소와 GitHub Actions 설정은 로컬에 준비했다. 여러 연결 계정 중 대상 선택을 기다리고 있으며 GitHub 원격 저장소 생성·push, Supabase 프로젝트 생성·마이그레이션·seed·계정 발급, Vercel 배포는 수행하지 않았다. 운영 데이터는 변경하지 않았다.

보호자 동의·철회, 학생 계정 관리 화면, 기관 경계, 대회 접수본 교체·철회, 개인정보 보관·삭제, 실제 사용자 성능·복구 검증 등은 `BACKLOG.md`의 후속 작업으로 남아 있다.
