# 책숲 0.7.0 · 수업 기록 복구와 전체 이력 관리

승인된 7가지 개선을 기존 인증·학급 권한·동의·불변 제출본·보고서 검토 절차에 연결한다.

1. 새 간편 독서 기록, 활동지 답안, 교사 양식과 활동 피드백의 개인 서버 초안을 7일 보관한다. 계정·학급·활동·제출 버전을 구분하고 재진입 시 본인이 복원을 선택한다. 수정 충돌은 두 초안을 비교한 후 선택하며 일시 연결 오류만 같은 요청으로 최대 세 번 재시도한다. 본인이 선택한 초안 파일 보관·불러오기를 제공하며 공용 PC에 자동으로 원문을 저장하지 않는다. 정식 제출·공개는 별도이다.
2. 공유 링크와 공개 보고서를 각각 전체 검색·학생별 조회·상태별 목록·독립 페이지로 관리한다. 학생의 현재 유효 링크를 이전 페이지까지 모두 해제할 수 있다. 이미 전달한 외부 사본을 회수했다고 표시하지 않는다.
3. 활동·최신 제출본·성장 근거를 전체 보관 범위에서 검색한다. 한 번에 30개만 응답하며 총 건수와 다음 목록을 제공한다. 미확인 제출을 먼저 표시하고 상태·학생·기간을 구분한다. 마감 연장·다시 열기는 revision 충돌과 변경 이력을 검사하며 배부한 문제·학생의 제출 원문·이미 확정한 보상은 바꾸지 않는다.
4. 완료한 활동지·퀴즈와 종이 활동 관찰을 최대 3개 선택하여 성장 보고서의 해당 판에 고정한다. 기존 대표 글 최대 3편도 유지한다. 원문·교사 피드백을 직접 확인하고 별도 검토·공개하며 같은 고정 내용을 Word·인쇄·CSV·Google 문서·시트 및 해당 보고서의 보호자 공유에 사용한다. 원문이 바뀌면 공개 전 새 판을 요구한다.
5. 새 전체 흐름을 Android Chrome·iPhone WebKit 에뮬레이션에서도 검사한다. 초안 복구·연결 중단 후 재시도·배부·제출·교사 확인·도서 CSV·보고서 파일·보호자 공유 해제·접근성을 포함한다. 실제 휴대전화·학교망·실물 기기 승인은 자동 검사와 구분한다.
6. 공방의 첫 화면은 오늘 할 일이다. 교사의 제작실·활동 확인·도서·성장 근거·공유·학급 기준과 학생의 활동·리듬·도감 메뉴를 분리한다. 전체 도구 보기는 보조 진입 경로로 유지한다.
7. 보유 도서는 UTF-8 CSV 예제를 제공하고 등록 전 100권 전체를 미리 확인한다. 오류 자료 행을 안내하고 ISBN이 같은 도서의 위치·권수·설명을 갱신한다. 개별 수정·삭제는 revision과 담임 권한을 검사하며 도서 목록 삭제로 학생 독서 기록을 지우지 않는다. 실시간 대출 시스템과는 별도이다.

새 초안과 마감 이력은 private 스키마 RLS 및 직접 접근 차단으로 보관하며 기존 개인정보 삭제·만료 정리와 백업에 포함한다. 운영 정본에는 합성 학생·학급을 만들지 않는다. AI 생성 활성화·새 외부 보관 장치·대체 운영자 수락·실제 서버 전환은 이 릴리스의 자동 완료 항목이 아니다.
