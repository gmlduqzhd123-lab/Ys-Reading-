# 책숲 개발 백로그

## 2026-10-31 · 로컬 Google·운영 계정 준비

사용자 결정으로 공개 배포와 Vercel 연동을 보류했다. 이메일 PKCE 로그인·확인된 이메일에 한정한 최초 운영자 등록, Google 클라이언트의 비공개 설정 가져오기 도구를 구현했다. Google Cloud의 책숲 전용 프로젝트·로컬 OAuth 클라이언트·Drive API·테스트 사용자를 준비했다. 실제 이메일 인증·운영자 등록 완료와 Google OAuth 동의·파일 생성 확인은 각각 실제 결과로 구분한다. 상세는 [LOCAL-ACCOUNT-GOOGLE.md](LOCAL-ACCOUNT-GOOGLE.md)와 최신 검증 기록을 따른다.

## 2026-10-30 · 다음 개발 묶음: 계정·참여·기록 운영

`/operations`와 `/account`에 학생 계정 일괄 발급·비밀번호 복구·첫 로그인 비밀번호 변경, 동의 근거 요청과 운영자 확인·학생 철회, 보관 기간·삭제 미리보기·승인·실행·재시도, 교사 권한·학급/모임 인계·계정 정지·운영 이력을 구현했다. Supabase Edge Function과 DB 계정 상태·세션 차단을 사용한다. 상세 동작과 초기 운영자 준비는 [ACCOUNT-OPERATIONS.md](ACCOUNT-OPERATIONS.md)를 따른다. 실제 학교의 동의 확인이나 공개 웹 배포 완료를 뜻하지 않는다.

## 2026-10-30 · 4단계 기능 갱신

계정용 `/hub`에 독서 기록·도서 검색·내보내기, 캐릭터·경험치·배지, 학급·학년 공유·글쓰기, 학급 경제 교실을 구현했다. Supabase 개발 프로젝트의 DB·미션을 반영하고 가상 계정으로 실제 로그인·권한·활동·출력 연결을 확인했다. Google Docs·Sheets 연결 코드는 구현했지만 별도 OAuth 앱 설정과 실제 교사 승인은 대기다. 웹 공개 배포와 실제 학생 수업 검증도 아직 수행하지 않았다. 상세는 [FOUR-STAGES.md](FOUR-STAGES.md)와 최신 [VERIFICATION.md](VERIFICATION.md)를 우선한다.

아래 BF/ST 항목과 날짜별 검사는 앞선 개발 시점의 이력이다. ‘실제 운영 전 필수’ 항목은 운영 주체의 확인이 필요하며 이번 구현만으로 해제되지 않는다.

기준일: 2026-10-30. 이 문서는 현재 작업 상태를 기록하며 서비스 출시를 증명하지 않는다. `implemented`는 파일에 구현이 있음을, `verified`는 적힌 검증을 통과했음을 뜻한다. 계획된 항목을 구현 완료로 표시하지 않는다.

## 상태 기준

- `planned`: 요구사항 또는 후속 계획. 구현 완료를 확인하지 않음.
- `in_progress`: 현재 구현 또는 통합 중. 통과해야 할 검증이 남음.
- `implemented`: 코드·콘텐츠·문서가 있음. 운영 환경 검증 완료와 다름.
- `verified`: 명시한 범위의 검증을 통과함. 별도 출시 차단 조건은 여전히 적용.
- `release_gate`: 실제 학생 대상 운영을 시작하기 전에 해결해야 함.

## 상태 갱신 원칙

실제 실행하지 않은 검사나 외부 연결을 완료로 적지 않는다. 구현 담당자는 변경한 파일, 확인한 시나리오, 남은 제한을 함께 기록한다. 공개 배포가 성공하더라도 학생 대상 운영 차단 조건이 남아 있으면 서비스 출시 완료로 표현하지 않는다.
